Subprocessors & service providers

Last updated: 7 November 2026

This page identifies external providers integrated into the current Taal Lab website and applications. A provider is used only where needed for the relevant feature; not every provider receives information from every user.

Cloudflare

Purpose: Website and application hosting, Worker runtime, database and delivery infrastructure.

Information: Account and application data processed by the hosted service, technical request information and database records.

Cloudflare Data Processing Addendum

Backblaze

Purpose: Private file storage for transfers, OCEAN assets and digital-product files.

Information: Uploaded file content, file names, object identifiers and storage metadata.

Backblaze Data Processing Addendum

Google

Purpose: Google sign-in, Google Drive and Google Calendar integrations, and Google Fonts loaded by the website.

Information: Google account identifiers and profile information, connected-service tokens and calendar/drive data required by features you choose, plus technical connection information for font requests.

Google Cloud Data Processing Addendum

Resend

Purpose: Account verification, password recovery, security and transactional email delivery.

Information: Recipient email addresses and the content/metadata of transactional messages.

Resend Data Processing Addendum

Razorpay

Purpose: Digital-product payment checkout and payment verification.

Information: Order references, amount, currency, customer name, phone number and payment status. Payment card and bank credentials are handled by Razorpay.

Razorpay Privacy Policy

Unsplash

Purpose: OCEAN cover-photo search, photo display and required download-event tracking when a photo is selected.

Information: Search terms, selected photo identifiers and image interaction events.

Unsplash API Terms

Emoji API

Purpose: Emoji search and category results in OCEAN.

Information: Search terms submitted through the emoji picker.

Emoji API website

Applicability depends on the Taal Lab account, product and agreement in use. We are reviewing those provider arrangements and will update this list if the integrations change.
